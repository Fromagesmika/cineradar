# CinéRadar

Film recommendations through a chat, built on MovieLens, TMDB and ReDial. The code is on GitHub:
https://github.com/Fromagesmika/cineradar

The app opens with an access code, set in the Space settings as the `CINERADAR_ACCESS_CODE` secret.
